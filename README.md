# Galaxy Overhead

A phone-first sky map that draws the Milky Way's structure over the night sky and shows which part of the galaxy you are looking at.

Live: https://kmendelev.github.io/galaxy-overhead/

- **Whole sky / Horizon views:** drag to turn, pinch to zoom, tap anything for details.
- **Point mode:** hold the phone up and the map follows it, using the motion sensors and compass. Drag sideways to line it up with a star you know.
- **Galaxy panel:** a top-down Milky Way map showing which part of the galactic plane is above your horizon.
- **Stories:** tap a planet, a bright star, a nebula or a historic object (Tycho's and Kepler's supernovae, 61 Cygni, Mira, Cygnus X-1) for the history, science and literature attached to it.
- **Human-made objects layer** (off by default): the ISS, Hubble, Tiangong and Vanguard 1 from live orbit data, with pass predictions; Voyager 1 and 2, Pioneer 10 and 11 and New Horizons; Webb and Euclid at L2; the Apollo sites; the Mars rovers; and the 1974 Arecibo message.

## Build

`index.html` (GitHub Pages) and `artifact.html` (claude.ai page) are generated:

```
python3 build.py            # uses data/data.js
```

Stories, historic objects and human-made objects live in `src/lore.js`. `data/data.js` is generated by `tools/prep.py` from the `d3-celestial` npm package (data folder) and the `geonamescache` PyPI package:

```
python3 tools/prep.py <d3-celestial>/data <geonamescache>/data <out-dir>
```
